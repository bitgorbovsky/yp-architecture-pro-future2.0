# Технологический радар

**Стадии применения**:
* **Исследование** - инструмент, подход, технология только появилась или является новой для компании, проходит этап исследования (изучение материалов, прохождение обучения и так далее).
* **Испытание** - инструмент, подход, технология проходит стадию испытаний на стендах, делаются прототипы служб для выполнения определённых задач, оценивается качество решения задач с помощью данной технологии.
* **Промышленная эксплуатация** - инструмент, подход, технология внедрена и используется.
* **Вывод из эксплуатации** - инструмент, подход, технология признаётся устаревшей и запланирован вывод из эксплуатации.
**Классификация**:
* **Языки программирования**.
* **Хранилища, базы данных, очереди и обменники сообщений**.
* **Архитектурные подходы**.

# Архитектурные подходы

| Название                                        | Назначение                                                                                                                                                                                                                                                                                | Стадия применения |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| **Распределённое владение данными** (Data Mesh) | Подход к распределённому владению данными, позволяющий различным домена держать свои данные внутри себя, оперировать ими, проводить самостоятельную аналитику и использовать подход "данные как продукт". Это убирает издержки, связанные с излишней централизацией аналитических систем. | **Испытание**     |
| **Событийная архитектура** (Event Oriented)     | Подход к построение систем для большей масштабируемости и меньшей сцепленности служб и компонентов                                                                                                                                                                                        | **Испытание**     |
| **Self-service BI**                             | Подход, при котором сотрудники компании могут самостоятельно работать с данными. Для этого предлагаются удобные инструменты, использование которых позволяет не обращаться к помощи специалистов.                                                                                         | **Исследование**  |
